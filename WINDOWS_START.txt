ROTORAS GENERATOR - WINDOWS BOUWPAKKET (basis v0.22)

Dit pakket bevat de volledige Windows-appbroncode. Er zit nog geen gebouwde
installatie-EXE in: de laatste compilatiestap moet op Windows plaatsvinden.

LOKAAL BOUWEN (eenmalig op een Windows 10/11 x64 bouwcomputer)
1. Installeer Node.js 24 LTS: https://nodejs.org/
2. Installeer Microsoft Visual Studio Build Tools:
   https://visualstudio.microsoft.com/visual-cpp-build-tools/
   Selecteer Desktop development with C++ en de Windows SDK.
3. Installeer Rust via https://rustup.rs/ met de MSVC-toolchain.
4. Herstart de computer en pak dit pakket uit in een lokale map.
5. Open Bouw_Windows.cmd. Deze controleert de invoertests en configuratie
   en bouwt vervolgens de app en de Nederlandstalige installer.
6. De map met de installer wordt na succes automatisch geopend.

BOUWEN VIA GITHUB (geen bouwsoftware op de werkcomputer nodig)
1. Maak een eigen repository en zet de inhoud van deze broncodemap in de root,
   inclusief de verborgen map .github. Houd het project desgewenst privé.
2. Open Actions > Bouw Rotoras Windows > Run workflow.
3. Download bij de geslaagde run het artifact
   Rotoras-Generator-Windows-installatie, pak dit uit en start de EXE.
   De workflow publiceert niets en maakt geen release aan.

NA INSTALLATIE
De app wordt voor de huidige Windows-gebruiker geïnstalleerd.
Als WebView2 ontbreekt, downloadt de installer de Microsoft-runtime.
Project opslaan bewaart alle originele invoer in .rotoras.json.
Open CSV / project kan bestaande bestanden openen.
CSV-export gebruikt de ingestelde map met een Windows Opslaan als-dialoog.
De browser-HTML heeft een eigen automatische opslag. Open je opgeslagen
.rotoras.json eenmaal in de Windows-app om je huidige as over te nemen.

EERSTE CONTROLE OP WINDOWS
Open een bestaand project, controleer lengtewijzen en oorspronkelijke waarden.
Sla het project op, sluit de app en open het opnieuw.
Exporteer CSV naar de bedoelde map en controleer het model in Inventor.
Controleer ook Afdrukken / PDF, zoom en de drie invoertabbladen.

Bouwstatus: interface en configuratie hier gecontroleerd. Rust/Windows-host,
installer en Windows-dialogen moeten nog op Windows gebouwd en getest worden.
